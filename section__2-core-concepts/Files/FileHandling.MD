# File Handling

## 📂 Core Concepts of File Handling in Java
| Concept                 | Key Classes                                                          | Use                                           |
| ----------------------- | -------------------------------------------------------------------- | --------------------------------------------- |
| **Reading Files**       | `FileReader`, `BufferedReader`, `Scanner`, `Files` (NIO)             | Read data from text or binary files           |
| **Writing Files**       | `FileWriter`, `BufferedWriter`, `PrintWriter`, `Files`               | Write data to files                           |
| **File Operations**     | `File`, `Files`, `Paths`                                             | Create, delete, move, rename, check existence |
| **Stream-Based I/O**    | `InputStream`, `OutputStream`, `FileInputStream`, `FileOutputStream` | For binary file I/O                           |
| **Character-Based I/O** | `Reader`, `Writer`                                                   | For text file I/O                             |
